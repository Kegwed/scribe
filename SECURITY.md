# Security

If you find a security problem in Scribe, please report it privately through GitHub's private vulnerability reporting: open the repository's [Security tab](https://github.com/Kegwed/scribe/security) and choose **Report a vulnerability**, or go straight to [the reporting form](https://github.com/Kegwed/scribe/security/advisories/new). Please don't open a public issue, pull request or discussion about it. Reports are read by the maintainer, who will reply there, agree a fix and a disclosure date with you, and credit you in the advisory unless you'd rather not be named.
